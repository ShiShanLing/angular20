本地文件工具

知情同意书转换工具

拖入 Word 文件

DOCX

统一包装为 legal-permission HTML
移除链接跳转并保留文字样式

HTML

橙色邮箱继续保持橙色
输出前自动验证 JSON 字符串

TXT
